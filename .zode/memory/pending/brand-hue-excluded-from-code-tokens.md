title: "Electric teal accent hue is excluded from code token palette"
tags: "theme, color, code-tokens"
evidence: "end-of-turn extractor; user approval required"
---

The brand accent is electric teal (~185°, rgb 0x00c8b8) and the code token palette deliberately avoids the 164-206° hue band so brand and syntax never read the same way on screen. Code tokens use orchid, lilac, pink, indigo, periwinkle, and amber instead. Semantic greens (ok/warn/err) are also kept separate from brand green.
